# DevTask Hub

DevTask Hub is a simple task management project developed to practice Git, GitLab collaboration, branching, merge conflict resolution, and CI/CD.

## Features

- Basic task dashboard using HTML.
- JavaScript task validation.
- Automated build and test stages using GitLab CI/CD.
- Git branches, merge requests, and release tags.

## Technologies Used

- HTML
- JavaScript
- Node.js
- Git
- GitLab CI/CD

## Run the Tests

Install Node.js, open a terminal in the project folder, and run:

```bash
node test.js
```

Expected output:

```text
Tests Passed!
```

## Build

The GitLab CI/CD build job copies `index.html` into the `dist` directory.
